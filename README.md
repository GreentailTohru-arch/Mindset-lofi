## 直接打开（Windows，离线）

双击 `start-room.cmd`，浏览器会打开 `http://127.0.0.1:4173`。保留启动窗口，关闭窗口或按 Ctrl+C 停止服务。

交付目录已含 `dist` 预构建版本，无须重新安装依赖。离线入口仅需 Node.js；脚本会先使用 PATH 中的 Node，再尝试这台电脑已有的 Codex Node 运行时。不能直接双击 `index.html`，浏览器需要通过本地 HTTP 服务加载 JavaScript 模块。

## 开发

推荐 Node.js 22.12+。依赖已安装在此目录，可直接运行：

```sh
npm run dev
```

在新电脑首次使用源代码：

```sh
npm install
npm run dev
```

开发地址为 `http://127.0.0.1:5173`。首次安装依赖需要网络；安装后开发与预构建版本运行均不需要网络。

| 操作     | 桌面                         | 手机 / 平板                  |
| -------- | ---------------------------- | ---------------------------- |
| 旋转     | 左键拖动                     | 单指拖动                     |
| 缩放     | 滚轮                         | 双指捏合                     |

相机的距离、垂直角度、水平旋转范围和目标点平移均有限制。视角保持在剖面房间的开放侧，避免穿进墙壁或家具；并非第一人称行走模式。

- RGB：静态、呼吸、彩虹、波浪、极光、柔和随机变色、关闭；可调颜色、亮度和速度。选颜色会切换为静态模式。

- 物品菜单也是键盘操作入口：Tab 选择按钮，Enter 激活。

## 项目结构

```text
src/
  main.js                 渲染器、相机、OrbitControls、动画循环
  state.js                独立状态与平滑插值函数
  ui.js                   中文控制面板和可访问的物品菜单
  style.css               响应式悬浮界面
  ui-tokens.css           基础颜色
  interaction.js          射线拾取、拖动判定、高亮与提示
  scene/
    materials.js          木纹、布料、地毯、显示器画面
    primitives.js         可复用的几何体和盆栽
    room.js               地板、墙、真实窗口、窗帘与窗外景观
    furniture.js          家具和物品动画
    lighting.js           RGB 灯带、局部点光源与独立白光
tests/state.test.js        灯光互不影响、重置、动画平滑回归检查
scripts/serve.mjs          无第三方依赖的离线静态服务
start-room.cmd            Windows 一键离线启动
```

增加物品时，在场景模块中创建 group，然后调用 `register(group, 名称, 提示, 动作)`。新物品会自动进入射线交互与物品菜单。需要持续动画时，在模块的 `update(dt, time)` 中更新；需要重置的状态应加入 `state.js` 的默认值。

## 渲染与性能

使用 ACESFilmicToneMapping、sRGB 输出、限制像素比、柔和 PCF 阴影。Bloom 默认未启用，以保持灯光克制。RGB 只有三个近距离点光源；白光用一个有限距离 SpotLight；床头、落地灯和窗户各用一个局部点光源。中性半球光和方向光提供基础可见度，仅方向光生成一张阴影图。地板使用 InstancedMesh；相同尺寸基础几何体复用。

程序化实时场景属于参考图的风格化实现，不是离线光线追踪渲染的逐像素复刻。色温为视觉近似。需支持 WebGL 2 并开启硬件加速；低性能设备可在 `main.js` 降低像素比上限或阴影图分辨率。窗口不可见时跳过渲染。
